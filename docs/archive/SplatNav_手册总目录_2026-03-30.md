## Pandoc 合并 PDF（示例）

在仓库根目录执行（需本机已安装 pandoc 与中文字体，路径按环境修改）：

```bash
cd /home/howard/Splat-Nav/docs/archive
pandoc \
  SplatNav_手册总目录_2026-03-30.md \
  SplatNav_卷0_基础知识编_2026-03-30.md \
  SplatNav_项目全景与上手手册_全量版_2026-03-30.md \
  -o SplatNav_手册_合并_2026-03-30.pdf \
  --pdf-engine=xelatex \
  -V mainfont="Noto Sans CJK SC" \
  -V geometry:margin=2.5cm \
  --toc --toc-depth=3
```

若合并失败，可分别导出三个 MD 再在 PDF 工具里拼接。
