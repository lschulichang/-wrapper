# 08 脚本入口说明

## 1. 目录

脚本目录：`/home/howard/Splat-Nav/scripts`

## 2. 脚本列表

1. `create_run_dir.sh <topic>`  
自动创建带时间戳的 `runs` 目录并写入基础环境信息。

2. `run_in_tmux.sh <window_name> <topic> "<command>"`  
在 tmux 会话中运行长任务，并将输出写入对应 `run_dir/stdout.log`。

3. `bootstrap_env.sh [env_name]`  
创建并安装 `splatnav` Conda 环境及核心依赖。

4. `env_health_check.sh [env_name]`  
检查 Python、Torch、CUDA 与关键模块导入是否正常。

5. `run_splatplan_smoke.sh <scene> <config_path> [method]`  
运行单次轻量规划 smoke test，用于快速验证链路。

6. `download_official_data.sh [env_name] [dest_root]`  
从官方 Google Drive 下载数据到 `/data`。

7. `link_official_assets.sh [data_root]`  
将下载后的 `data/outputs/traj` 软链接到上游仓库结构。

8. `retry_gdown_folder.sh <folder_url> <output_dir> [max_attempts] [min_frame_images]`  
Google Drive folder 自动重试下载，适用于网络不稳定场景。

9. `fill_missing_scene_files.sh <gdown_log_file> <scene_root>`  
根据已有 gdown 日志补齐缺失文件（用于下载中断后的精确补齐）。

10. `run_splatplan_smoke_tmux.sh <scene> <config_path> [method] [workdir]`  
在 tmux 后台运行 smoke test，并自动生成本次输出目录。

11. `run_official_style_batch.py`  
按官方实验风格进行多方法、多 trial 批跑，输出结构化 JSON（支持限制轨迹明细数量，避免文件过大）。

12. `visualize_batch_results.py`  
从批跑 JSON 自动生成可视化图：可行率柱状图、耗时箱线图、轨迹叠加图。

13. `run_overnight_12h.sh [scene] [config] [hours] [trials_per_method] [methods] [keep_traj_limit]`  
夜间连续批跑入口（默认 12 小时），每轮自动批跑并生成可视化结果。

## 3. 示例

```bash
# 1) 在 tmux 中安装环境
bash scripts/run_in_tmux.sh env_bootstrap bootstrap_env "bash scripts/bootstrap_env.sh splatnav"

# 2) 在 tmux 中做健康检查
bash scripts/run_in_tmux.sh env_check env_health "bash scripts/env_health_check.sh splatnav"
```
