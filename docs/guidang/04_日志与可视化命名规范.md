# 04 日志与可视化命名规范

## 1. 目录命名

所有运行结果统一放在 `runs/`，格式如下：

```text
runs/YYYY-MM-DD_HHMM_<topic>/
```

示例：

```text
runs/2026-03-29_1310_env_check/
runs/2026-03-29_1730_splatloc_official_scene/
runs/2026-03-30_0205_splatplan_ros_bridge/
```

## 2. 标准文件结构

```text
runs/YYYY-MM-DD_HHMM_<topic>/
  cmd.txt
  env.txt
  stdout.log
  notes.md
  metrics.json        # 可选
  assets/             # 图片、视频、可视化导出
```

## 3. 写入规范

1. `cmd.txt` 记录完整可复现命令。
2. `env.txt` 至少记录 Python、CUDA、GPU、commit。
3. `notes.md` 必须包含“成功点、失败点、下一步”。
4. 不要把临时推理文件散落在仓库根目录。
