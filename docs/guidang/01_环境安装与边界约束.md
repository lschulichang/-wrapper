# 01 环境安装与边界约束

## 1. 安全边界（必须遵守）

1. 仅操作 `howard` 账户路径。
2. 不修改其他账户内容（尤其 `cx*` 账户）。
3. 不升级 CUDA、不改系统驱动。
4. 项目大文件放 `/data/howard`，避免占用系统盘。

## 2. 路径布局

```text
/home/howard/Splat-Nav                     # 工程外层封装与文档
/data/howard/miniconda3                    # Miniconda 安装目录
/data/howard/splatnav/conda_envs           # Conda envs
/data/howard/splatnav/conda_pkgs           # Conda 缓存
/data/howard/splatnav/{datasets,checkpoints,cache,tmp,runs,logs,artifacts}
/data/howard/repos/splatnav-official       # 官方仓库（原样保留）
```

## 3. 当前已完成

1. Miniconda 已安装：`/data/howard/miniconda3`
2. `.condarc` 已配置，缓存与环境目录指向 `/data/howard/splatnav`
3. `runs` 软链接已建立到 `/data/howard/splatnav/runs`
4. 用户级 `tmux` 已安装于 Miniconda base

## 4. 常用命令

```bash

source /data/howard/miniconda3/etc/profile.d/conda.sh
conda activate base

# GPU 检查

# tmux（用户级）
/data/howard/miniconda3/bin/tmux ls
```
