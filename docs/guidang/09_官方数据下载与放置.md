# 09 官方数据下载与放置

## 1. 官方资源链接

Google Drive：`https://drive.google.com/drive/folders/1K0zfpuAti43YIBK5APFd-Yv73CvljgMC?usp=sharing`

## 2. 下载策略

1. 统一下载到 `/data/howard/splatnav/datasets/splatnav_official`。
2. 下载完成后，用软链接接到上游仓库目录结构。
3. 不把大数据放在系统盘 `/`。

## 3. 命令

```bash
# 在 splatnav 环境中下载
bash scripts/download_official_data.sh splatnav /data/howard/splatnav/datasets/splatnav_official

# 将数据映射到官方仓库预期路径
bash scripts/link_official_assets.sh /data/howard/splatnav/datasets/splatnav_official
```

## 4. 验证

```bash
find /data/howard/repos/splatnav-official/outputs -name config.yml | head
ls -la /data/howard/repos/splatnav-official/data
```

## 5. 注意事项

1. 首次下载可能耗时较久，建议放在 tmux 后台执行。
2. 若中途断网，脚本支持继续下载（`--continue`）。
3. 若遇到 Google Drive 文件访问限制，可能出现“folder 可列出、单文件不可拉取”的情况。
4. 临时可跑方案：
   1. 优先确保 `colmap/sparse/0` 下载完整；
   2. 使用 `colmap_to_json` 生成 `transforms.json + sparse_pc.ply`；
   3. 过滤 transforms 到本地已存在图片，先完成代码链路验证。
