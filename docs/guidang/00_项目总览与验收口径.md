# 00 项目总览与验收口径

## 1. 项目目标

在 2026-05-01 前完成以下事项：

1. 在当前 4090 工控机完成 Splat-Nav 非实机复现。
2. 作者场景中跑通核心链路（Splat-Loc + Splat-Plan）。
3. 输出可展示 demo 和可复现实验记录。
4. 形成「学弟最短路径」文档体系。

## 2. 范围边界

- 包含：离线流程、仿真流程、可视化、日志沉淀、外层工程化封装。
- 不包含：实机部署、系统驱动级改动、CUDA 升级。

## 3. 资源与路径规范

1. 仓库根目录：`/home/howard/Splat-Nav`
2. 数据盘根目录：`/data/howard/splatnav`
3. 运行结果目录：`/home/howard/Splat-Nav/runs`（软链接到 `/data/howard/splatnav/runs`）
4. 官方仓库目录：`/data/howard/repos/splatnav-official`

## 4. 阶段验收标准（Definition of Done）

### D1. 环境可用

1. Conda 可用，环境创建和激活正常。
2. GPU 可见，CUDA 运行环境与项目兼容。
3. 所有大文件默认落盘到 `/data/howard`。

### D2. 链路跑通

1. 能复现至少 1 组作者场景定位结果。
2. 能复现至少 1 组作者场景规划结果。
3. 有可视化结果（轨迹/位姿/视频其一或多项）。

### D3. 工程沉淀

1. 有最短运行命令与步骤文档。
2. 有常见故障排查文档。
3. 有阶段性复盘和下一步计划。

## 5. 风险清单（动态更新）

1. 上游依赖版本变化导致安装失败。
2. 数据下载中断或链接失效。
3. 显存/内存不足导致运行中断。
4. ROS2 与算法接口版本不一致。
